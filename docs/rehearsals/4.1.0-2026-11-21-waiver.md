# Two-computer rehearsal waived (not rehearsed): Flightdeck 4.1.0

- Version: 4.1.0
- Date: 2026-11-21
- Decision: the project owner waived the two-computer rehearsal (docs/rehearsals/README.md, *The release gate*) for this release, under the owner's standing rule that a waiver is recorded, not asked for.

## Why it was asked for

4.1.0 is a minor release. It adds one AI assistant skill, `flightdeck-walk-run`, to `.flightdeck/skills/`, with its row in `AGENTS.md` and `docs/skills.md`. It also adds Linked runs on a run's screen, the Ship a service change example family, the commands page and a wider What's new. The commands change only in what `flightdeck next` reads and prints: it adds `waitingOn` and, under contract 2, reads `reports/` and `report-decisions/`, and it stays read-only. The skill only runs commands that already ship: `flightdeck next` and `run`, which only read, `flightdeck report`, which writes one new report a person accepts or declines, and `flightdeck todo`, which writes one new request a person decides. Nothing in `src/storage/`, the run, notes or record formats, the saving and sync code in `src/ui/app.js`, the commands or the connection check changes, so the release gate doesn't apply. The waiver is recorded so every release has its record.

## What the rehearsal would have covered

On a test folder, with one computer on 4.0.0 and the other on 4.1.0: Update of the AI assistant files on one while the other has the folder open, and an assistant walking a run on one computer while the recorder checks its steps on the other.

## What covers it instead

Automated tests in `./test/run.sh`: the walk-run skill's rule and the skills guide rule in `test/assistant-start.test.js` (the skill fails first: it wasn't there), the AGENTS.md inventory rules in `test/agents-inventory.test.js`, the install and update rules, the baselines check, and the report and to-do command rules in `test/cli.test.js` and the to-do suites the skill relies on.

## What isn't proven on real OneDrive

How Update of the AI assistant files behaves while OneDrive is still syncing the folder on the other computer, as for every release that changes those files, and how long an assistant's report or to-do request takes to show on the recorder's computer.
