# Two-computer rehearsal: Flightdeck 1.22.0 (waived)

- Version: 1.22.0
- Date: 2026-10-20
- Decision: the project owner waived the two-computer rehearsal (docs/onedrive.md, *Release gate*) for this release.

## Why it was in question

1.22.0 adds browser Back and Forward (docs/design.md section 29). It changes no file format, nothing in `src/storage/`, no write or sync path and not the connection check. It touches `useFs()` in `src/ui/app.js` only to clear forms tied to the old folder and to replace the history entry on a folder switch, which is why the rule's letter was arguable.

## What isn't proven on real OneDrive

Nothing in this release writes differently, so the rehearsal's steps 0 to 13 would exercise 1.21.0 behavior. Not rehearsed: switching team folders and Reconnect on real OneDrive with Back and Forward in use.

## What still runs by hand

The one-computer browser check in Edge and Chrome from a real `file://` path (Windows `file:///C:/…` and a OneDrive path): Back and Forward through each kind of screen, the mouse buttons, Alt+Left inside a note box, the address bar after each move, a reload on a run link (with Reconnect) and Back across it, a bookmark to a run, and a screen reader reading the heading after Back.
