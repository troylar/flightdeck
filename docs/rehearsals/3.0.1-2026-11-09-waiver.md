# Two-computer rehearsal waived (not rehearsed): Flightdeck 3.0.1

- Version: 3.0.1
- Date: 2026-11-09
- Decision: the project owner waived the two-computer rehearsal (docs/rehearsals/README.md, *The release gate*) for this release, under the owner's standing rule that a waiver is recorded, not asked for.

## Why it was asked for

3.0.1 is a patch release. It changes the AI assistant files and the offline folder check (`AGENTS.md`, the references and skills in `.flightdeck/skills/`, and `check_folder.py`, which only reads), and one read in `src/storage/repo.js`: before Publish, `childProcsFor` now also reads the checklist a `{for.each}` step runs, as it already read a `{run.process}` step's, so a loop pinned with `version:` publishes and its child checks run. The library view and the linked-step warnings (`src/core/library.js`, `src/core/links.js`) list loops too; both only read. Publish writes the same files, in the same order, as before. The run, notes and scope record formats, the connection check, and the gated functions (`queued`, `canReplace`, `applyRunRead`, `useFs`, `acceptProposal`, `mutateRun`, `recover`) are byte for byte as in 3.0.0. The waiver is recorded so every release has its record.

## What the rehearsal would have covered

On a test folder, with one computer on 3.0.0 and the other on 3.0.1: a loop pinned with `version:` published on 3.0.1 and run on both; the same run, draft and loop open on both, edited and answered on each in turn; and Update of the AI assistant files on one while the other has the folder open.

## What covers it instead

Automated tests in `./test/run.sh`: the loop publish, library and linked-step rules in `test/loops.test.js` (written to fail first, through `repo.publish` with nothing handed in), the checker parity rules in `test/checker.test.js` for pinned loops and scope records (each written to fail first), the Module results example rule in `test/docs.test.js`, the AGENTS.md inventory and update rules in `test/agents-inventory.test.js` and `test/assistant-start.test.js`, the app suites, and the cross-version tests.

## What isn't proven on real OneDrive

How Update of the AI assistant files behaves while OneDrive is still syncing the folder on the other computer, as for every release that changes those files.
