# Two-computer rehearsal waived (not rehearsed): Flightdeck 2.16.1

- Version: 2.16.1
- Date: 2026-11-05
- Decision: the project owner waived the two-computer rehearsal (docs/rehearsals/README.md, *The release gate*) for this release, under the owner's standing rule that a waiver is recorded, not asked for.

## Why it was asked for

2.16.1 is a patch release that changes only how the work screens are laid out: the shared header of Edit and Practice, and one spacing scale across the work screens. The release gate isn't required: nothing changed in `src/storage/`, the run or notes formats, the connection check, or the gated functions (`queued`, `canReplace`, `applyRunRead`, `useFs`, `acceptProposal`, `mutateRun`, `recover`), each byte for byte as in 2.16.0. The waiver is recorded so every release has its record.

## What the rehearsal would have covered

On a test folder, with one computer on 2.16.0 and the other on 2.16.1: the same run and the same draft open on both, edited and answered on each in turn.

## What covers it instead

Automated tests in `./test/run.sh`: the header and spacing rules in `test/ui-states.test.js` and `test/views.test.js` (each written to fail first), the navigation, practice and app suites, and the cross-version tests, now with 2.16.0 recorded.

## What isn't proven on real OneDrive

Nothing this release changes reaches the team folder.
